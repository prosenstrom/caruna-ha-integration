# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Use [private vulnerability reporting](https://github.com/prosenstrom/caruna-ha-integration/security/advisories/new) on this repository.

## Supported versions

Only the latest release of this integration is supported.

## Credentials

This integration stores a Caruna+ email and password in the Home Assistant config entry and holds a session token at runtime. Do not commit credentials, tokens, or captured API responses that contain personal data.
